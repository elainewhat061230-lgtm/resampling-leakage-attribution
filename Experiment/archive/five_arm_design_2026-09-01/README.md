# 归档：五臂设计（B/A/C/C₂/D/E）全部产物 —— 2026-09-01 定稿版

**归档日期**：2026-09-25　**状态**：只读证据，**不再进入主分析**。
**取代者**：四状态有序路径分解（CON → LON → LMN → LMB），代码 `Experiment/code/states.py`。

## 为什么归档

五臂设计把三个机制各配一对互不处于同一路径的对照（③ = C − B，② = D − C₂，① = E − B），
三项之和与观测总差 A − B 不相等（中位缺口 F1 −0.0103、AUC −0.0150，55–63% 的单元格缺口 > 0.01），
且 B 臂与 A 系臂的原始训练/测试划分不同、预处理在全量数据上拟合。
新设计让四个状态共享同一原始折分与逐折（仅 O_tr 拟合的）预处理，相邻状态只差一个条件，
三个贡献逐折逐种子**代数恒等**地加总为总虚高。
